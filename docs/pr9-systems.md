# Additional system mappings

Verified against `/storage/.config/emulationstation/es_systems.cfg` on an Anbernic RG DS running ROCKNIX 20261001. The palette filename is an internal asset name; the include condition must match the firmware’s theme value.

Supervision is the Watara system; Super Cassette Vision is the separate Epoch system. Odyssey² and TIC-80 intentionally use palette filenames that differ from the firmware theme values.
